# Шаблон текущей доски приоритетов — кандидат v2

Кратко: это **шаблон**, а не текущая доска проекта. Пустые строки не означают отсутствие задач и не могут использоваться как источник текущего состояния.

## Как использовать

КООРДИНАТОР создаёт отдельную актуальную доску из этого шаблона и фиксирует в ней только подтверждённые приоритеты. В активных источниках проекта должна находиться именно заполненная актуальная доска, если такой источник нужен текущему циклу.
