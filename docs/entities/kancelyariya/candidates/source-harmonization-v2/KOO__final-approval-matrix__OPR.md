## Что выполнить после решения A

После явного утверждения организационно-технического пакета:

1. заменить активные источники утверждёнными редакциями;
2. удалить из активного набора поглощённые `draft/proposed-amendments`, сохранив их в legacy/archive как provenance;
3. применить recovery v1.2 к действующим recovery-пакетам Сущностей, начиная с КАНЦЕЛЯРА и КООРДИНАТОРА;
4. пересчитать контрольные суммы после каждой фактической замены;
5. не создавать «актуальную доску» из шаблона: текущая доска должна содержать только подтверждённое состояние.
